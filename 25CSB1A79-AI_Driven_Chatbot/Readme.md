Title: An Intelligent Agentic AI-Driven Self-Healing C++ Compiler Debugger and Attack Vault Architecture
What it Does:AI-powered C++ compiler and debugger that helps users identify, understand, and fix compilation, runtime, and semantic errors.
It also integrates Agentic AI security to detect and block malicious prompts, policy bypass attempts, and unsafe AI-generated fixes.
Additionally, it includes a self-healing mechanism for automatic code correction and an Attack Vault to store and analyze security threats, 
making the debugging process safer and more efficient.
