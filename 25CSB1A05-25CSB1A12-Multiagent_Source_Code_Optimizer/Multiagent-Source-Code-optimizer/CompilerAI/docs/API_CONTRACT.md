# CompilerAI — REST & SSE API Contract

## Base URL
`/api`

---

## 1. Health & Capabilities Check
`GET /api/health`

### Response (200 OK)
```json
{
  "status": "healthy",
  "service": "CompilerAI - Optimization Studio",
  "version": "0.1.0",
  "demo_mode": true,
  "adapters": {
    "optimization": "mock",
    "security": "mock"
  },
  "llm_connection": "not_configured",
  "supported_modes": ["pipeline", "optimize", "security"],
  "supported_languages": ["cpp", "c", "rust", "python"]
}
```

## 2. Start Execution Run
`POST /api/runs`

### Request Body
```json
{
  "mode": "pipeline",
  "language": "cpp",
  "source_code": "int sumArray(int* arr, int n) { int sum; for(int i=0; i<=n; i++) sum += arr[i]; return sum; }",
  "inference_mode": "heuristics",
  "options": {}
}
```

### Response (202 Accepted)
```json
{
  "run_id": "run-4f3a8b1c",
  "status": "queued",
  "mode": "pipeline",
  "created_at": "2026-11-18T14:20:00Z",
  "message": "Run queued and orchestrator initiated"
}
```

## 3. Server-Sent Events Stream
`GET /api/runs/{run_id}/events`

Streams events of shape:
```json
{
  "run_id": "run-4f3a8b1c",
  "seq": 1,
  "type": "agent_started",
  "agent": "optimization",
  "stage": "optimization",
  "status": "running",
  "timestamp": "2026-11-18T14:20:01Z",
  "message": "Optimization Agent started analysis pass",
  "data": {}
}
```

### Event Lifecycle Types
- `run_started`: Run has been picked up by the orchestrator.
- `agent_started`: Specified agent has begun analysis.
- `agent_progress`: Real-time progress percentage / progress update.
- `agent_log`: Detailed transformation or finding log.
- `agent_artifact`: Output artifact produced.
- `agent_completed`: Agent completed successfully.
- `agent_failed`: Agent encountered an error.
- `pipeline_stage_changed`: Transitioning to next downstream stage.
- `warning` / `error`: Diagnostic warnings or errors.
- `run_completed`: Entire run finished.
- `run_partially_completed`: Run ended with partial results.
- `run_cancelled`: User requested cancellation.
