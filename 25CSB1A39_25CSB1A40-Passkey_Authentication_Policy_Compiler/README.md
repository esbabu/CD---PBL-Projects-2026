# Passkey-First Authentication Policy Compiler

**Roll Number:** 25CSB1A39 & 25CSB1A40

**Project Title:** Passkey-First Authentication Policy Compiler

## Project Description
An Agentic AI-based compiler designed to analyze and enforce authentication security policies,
including password and passkey-based authentication.

## Project Contents

1. Source Code – Complete implementation of the project.
2. Documentation – Project report and technical documentation.
3. Architecture – Existing and proposed system architecture.
4. Project Website – User interface and project demonstration.
5. Screen Recording – Working demonstration of the project.

## Technologies Used
- Compiler Design
- Agentic AI
- C++
- Python
- HTML, CSS and JavaScript
