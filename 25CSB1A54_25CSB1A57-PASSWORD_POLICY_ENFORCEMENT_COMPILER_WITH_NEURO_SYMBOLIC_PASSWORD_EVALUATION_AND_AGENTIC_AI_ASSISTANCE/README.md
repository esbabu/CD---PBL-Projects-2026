## Project Description
A Password Policy Enforcement Compiler that combines compiler-based password policy processing, neuro-symbolic password evaluation and agentic AI assistance.

- ir.cpp, ir.h – Intermediate representation
- ir_analyzer.cpp, ir_analyzer.h – IR analysis
