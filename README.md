# Project Title: Compiler Error Explainer and Rewriting using AST and NLP
**Student Roll Number:** 25CSB1A72

## Project Files & Descriptions:

**1. Source Code:**
- Located in the `src` folder (and other `.py` files).
  
A complete Python/Flask web application implementing a dual-compiler architecture (GCC for diagnostics, Clang for AST extraction). The backend features a hybrid TF-IDF/Logistic Regression classifier, an Agentic Auto-Healer with 21 deterministic repair strategies, and a custom Static Application Security Testing (SAST) engine with over 55 CWE-mapped security rules. Includes the entire frontend UI (HTML/CSS/JS) and data benchmarking scripts.


**2. Documentation:**
- Located in the `reports` folder (or the PDF file I uploaded).
  
A comprehensive PDF report detailing the system architecture, the mid-to-end project evolution, and the experimental methodology. It includes the system pseudocode (Algorithms 1-6), dataset evaluation graphs (Confusion Matrix, F1-Score, and multi-model benchmarking), and a breakdown of the 55+ security metrics.


**3. Screen Recording:**
- **Google Drive Link:** https://drive.google.com/file/d/14zaxXuwrlTyeJ4pjoY4I61FmFtYvuVe5/view?usp=sharing
  
A live demonstration video walking through the end-to-end pipeline. The video shows the system parsing a 500+ line C++ file, generating the AST and DFA trace, automatically healing multiple syntax errors via the OBSERVE-PLAN-ACT-REPLAN loop, and successfully detecting and refusing to heal a malicious file containing command injection and buffer overflow vulnerabilities.
