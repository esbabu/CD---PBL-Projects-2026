### Project Overview
The **Multilingual Programming Language Compiler** (VITAL - Verified Isolated Translation and Automated Localization) is a Theory of Automata and Compiler Design platform designed to eliminate language and cognitive barriers in computer science education. It features:
- **Multilingual Source Code Support**: Native script programming in **English**, **Hindi**, **Telugu**, **Malayalam**, **Spanish**, and **Arabic** (with authentic RTL layout).
- **Full 5-Stage Compiler Pipeline**:
  1. Decoupled Multilingual Lexer / Tokenizer
  2. Recursive-descent AST Parser
  3. Static Semantic Analyzer & Symbol Table Management
  4. Deterministic AST Security Verifier
  5. Isolated Sandboxed Runtime Execution
- **Automated Error Guidance & Self-Healing**: Diagnostic engine providing human-readable, educational error feedback and deterministic automated syntax repair.
- **Modern Light-Mode Web IDE**: Monaco editor integration with live token stream, syntax tree inspection, symbol tables, and execution logs.
